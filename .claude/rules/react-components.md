# React Component Rules

- Use functional React components.
- Define component props with a TypeScript interface.
- Avoid inline business logic inside JSX.
- Include accessible labels for interactive controls. 

# React Specifications
 - Use React 18 for frontend development.
 - Use React Router for navigation and routing.
 - Use React Context for state management when appropriate.
 - Use React Testing Library for testing React components.
