# Testing Rules

- As we are developing a Java full stack application.
  # Backend Test Expectation
  - Backed Java classes should be tested with Mockito.
  - Validate test coverage once Backend testing for all java classess are done.
  # Frontend Test Expectation
  - Frontend React components should be tested with Jest and React Testing Library.
  - Test coverage should be validated once Frontend testing for all React components are done.
